# สรุปการปรับปรุงส่วน "ราคาผลไม้" ให้เป็นแบบ Real-time

## ผลการตรวจสอบแหล่งข้อมูล (ทำก่อนแก้โค้ดตามที่ขอ)

ตรวจสอบแล้วว่า **ตลาดไท** (talaadthai.com) และ **ตลาดสี่มุมเมือง** (simummuangmarket.com)
**ไม่มี Public API** ที่เปิดให้เว็บไซต์ภายนอกดึงข้อมูลราคาได้โดยตรง:

- talaadthai.com มีหน้า `/products` ที่แสดงราคาสินค้ารายวัน แต่เป็นหน้าเว็บสำหรับผู้ใช้ทั่วไป
  ไม่มีเอกสาร API/JSON endpoint สาธารณะสำหรับนักพัฒนา
- simummuangmarket.com มีหน้า `/pricing` ในลักษณะเดียวกัน ไม่มี Public API เช่นกัน
- ไม่พบว่าหน่วยงานรัฐ (กรมการค้าภายใน กระทรวงพาณิชย์, data.go.th) เผยแพร่ API ราคาขายส่งรายวัน
  ของสองตลาดนี้โดยเฉพาะ

**เพราะเหตุนี้ ผมจึงไม่เขียนสคริปต์ดึงข้อมูล (scraper) ไปยังสองเว็บไซต์นี้** เพราะ:
1. คุณระบุไว้ชัดเจนว่าห้าม Scraping ที่ผิดเงื่อนไข
2. เว็บไซต์ทั้งสองไม่มีการอนุญาต/เอกสาร API ให้บุคคลภายนอกดึงข้อมูลอัตโนมัติ
3. การ Scrape โดยไม่ได้รับอนุญาตอาจขัดกับข้อกำหนดการใช้งานของเว็บไซต์ต้นทาง

## สิ่งที่พบในโค้ดเดิม (ก่อนแก้ไข)

ที่จริงโค้ดเดิมของคุณ **ได้วางสถาปัตยกรรมที่ถูกต้องไว้แล้ว** ในส่วนท้ายไฟล์ (คอมเมนต์ `LIVE PRICE FEED`):

```
Frontend (fetchLivePrices) → อ่านไฟล์ prices.json → ถ้าไม่พบไฟล์ → แสดงสถานะ error
                                                    → ไม่สุ่ม/สร้างราคาใดๆ ทั้งสิ้น
```

หน้าเว็บ "อ่าน" ไฟล์ `prices.json` ที่ต้องถูกสร้าง/อัปเดตโดย backend ของคุณเอง (เช่น cron job ทุก 30–60 นาที)
วิธีนี้ไม่ติดปัญหา CORS เพราะเบราว์เซอร์ไม่ได้ยิง request ตรงไปยัง talaadthai.com/simummuangmarket.com เลย —
Backend ของคุณเป็นตัวกลางที่ไปดึง/บันทึกข้อมูลแทน (ต้องเป็นวิธีที่คุณมีสิทธิ์ทำ เช่น
ป้อนราคาด้วยมือจากประกาศราคาทางการ หรือได้รับอนุญาต/สัญญาความร่วมมือข้อมูลจากตลาดโดยตรง)

## สิ่งที่แก้ไขในรอบนี้ (เก็บโครงสร้าง/ดีไซน์เดิมทั้งหมด ไม่ลบอะไร)

ไฟล์: `index.html` — ส่วน "เปรียบเทียบตลาดไท vs ตลาดสี่มุมเมือง" (id="tab-price-market")

1. **ปุ่ม "🔄 อัปเดตราคา"** — เพิ่มปุ่มเรียก `fetchLivePrices()` ใหม่ด้วยตนเอง ปุ่มจะถูกปิดชั่วคราว
   ระหว่างกำลังโหลด
2. **สถานะ 🟢/🟡/🔴** — เพิ่ม emoji แสดงสถานะควบคู่กับจุดสีเดิม:
   - 🟢 = ดึงข้อมูลจาก `prices.json` สำเร็จ และมีราคาตรงกับรายการในตาราง
   - 🟡 = กำลังโหลด หรือพบไฟล์แต่ไม่มีราคาที่ตรงกับตาราง (ใช้ค่าประมาณการ)
   - 🔴 = ไม่พบไฟล์/ดึงไม่สำเร็จ → ข้อความ "ไม่สามารถดึงข้อมูล Real-time จากแหล่งข้อมูลนี้ได้"
     ตามที่คุณกำหนดไว้ พร้อมชี้ไปยังลิงก์แหล่งที่มาด้านล่างตาราง
3. **วันเวลาที่ตรวจสอบล่าสุด** — แสดงเวลาที่ระบบ "ตรวจสอบ" ล่าสุดเสมอ (ไม่ใช่แค่ตอนสำเร็จ)
   เพื่อความโปร่งใสว่าเช็คครั้งล่าสุดเมื่อไร แม้ในสถานะ error
4. **Animation เมื่อราคาเปลี่ยน** — ปรับให้ animation `price-live-updated` เล่นใหม่ทุกครั้งที่ค่าจริง
   เปลี่ยนไปจากเดิม (เดิมเล่นครั้งเดียวตอนโหลดสำเร็จ)
5. **ช่องค้นหาชื่อผลไม้** — เพิ่ม `<input>` และฟังก์ชัน `filterMarketPriceTables()` กรองแถวในตาราง
   ทั้งสองตลาดพร้อมกันแบบ real-time ขณะพิมพ์ (ทำงานฝั่ง client ล้วน ไม่กระทบข้อมูล)
6. ลิงก์แหล่งที่มา (talaadthai.com/products, simummuangmarket.com/pricing, moc.go.th) ที่มีอยู่เดิม
   ยังคงอยู่ครบถ้วน

ไม่มีการลบตาราง ข้อมูล หรือฟังก์ชันเดิมใดๆ ทั้งสิ้น

## วิธีตั้งค่าให้เป็น Real-time จริง (ทางเลือกที่ถูกต้อง)

เนื่องจากไม่มี Public API จากสองตลาด คุณมีทางเลือกหลักๆ ดังนี้:

### ทางเลือก A — ป้อนราคาด้วยมือ (ทำได้ทันที ไม่ผิดเงื่อนไขใดๆ)
สร้างไฟล์ `prices.json` วางไว้โฟลเดอร์เดียวกับ `index.html` บนเซิร์ฟเวอร์ที่โฮสต์เว็บ แล้วอัปเดตราคาด้วยมือ
(หรือผ่านฟอร์ม/แอดมินหลังบ้านง่ายๆ) วันละครั้ง:

```json
{
  "updated_at": "2026-08-28T09:30:00+07:00",
  "talaadthai": {
    "ทุเรียนหมอนทอง": "125-210 บ.",
    "มังคุด": "58-95 บ."
  },
  "simummuang": {
    "ทุเรียนหมอนทอง": "130-220 บ.",
    "มังคุด": "60-100 บ."
  }
}
```
หน้าเว็บจะดึงไฟล์นี้ทุก 1 นาทีอัตโนมัติ (หรือกดปุ่ม 🔄 อัปเดตราคา) โดยไม่มีปัญหา CORS เพราะเป็นไฟล์บนโดเมนเดียวกัน

### ทางเลือก B — ขอเชื่อมต่อข้อมูลอย่างเป็นทางการ
ติดต่อฝ่ายธุรกิจ/พันธมิตรของตลาดไท (talaadthai.com/partner) หรือตลาดสี่มุมเมือง เพื่อขอสิทธิ์เข้าถึงข้อมูลราคา
(feed หรือ API เฉพาะคู่ค้า) หากได้รับอนุญาตและมี API Key จริง ให้:
1. เก็บ API Key ไว้ฝั่ง backend เท่านั้น (เช่น ตัวแปรแวดล้อม `.env`) **ห้ามใส่ใน HTML/JS ฝั่งผู้ใช้**
2. เขียน backend endpoint (เช่น `/api/prices`) ที่เรียก API จริงด้วย Key ฝั่งเซิร์ฟเวอร์ แล้วบันทึกผลลง `prices.json`
   หรือส่งกลับเป็น JSON ให้หน้าเว็บเรียกแทน `LIVE_PRICE_JSON_URL`
3. ตั้ง cron/scheduled job รันสคริปต์นี้ทุก 30–60 นาที

### ทางเลือก C — ใช้แหล่งข้อมูลราคาสินค้าเกษตรที่เป็นทางการอื่น
เช่น ประกาศราคาสินค้าเกษตรของกรมการค้าภายใน กระทรวงพาณิชย์ (moc.go.th) ถ้าพบว่ามีชุดข้อมูลเปิด (Open Data)
ที่ตรงกับผลไม้ที่ต้องการ ก็สามารถใช้แหล่งนั้นแทนได้ในโครงสร้าง backend เดียวกัน — ต้องตรวจสอบเงื่อนไขการใช้ข้อมูล
ของแต่ละหน่วยงานก่อนใช้งานจริง

## วิธีตรวจสอบว่าข้อมูลเป็น Real-time จริง

- ดูข้อความสถานะเหนือ ตาราง: 🟢 = อัปเดตจาก `prices.json` จริง (มีเวลาที่มาจากไฟล์), 🔴 = ยังไม่เชื่อมต่อ
- เปิด DevTools → Network → ดู request ไปที่ `prices.json` (หรือ endpoint backend ของคุณ) แต่ละครั้งที่กดปุ่ม 🔄
- เทียบเวลาที่แสดงในหน้าเว็บกับเวลาที่คุณอัปเดตไฟล์ `prices.json` ล่าสุด

## ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บหลัก (แก้ไขแล้ว) |
| `prices.json` (ต้องสร้างเอง บนเซิร์ฟเวอร์จริง) | ไฟล์ข้อมูลราคาที่ backend/แอดมินอัปเดต |
